# SG-Net/1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Implement SG-Net/1 in SG-Gateway 23.01 as an independent closed Go runtime with SG-TLS/1, per-device credentials, TCP/UDP relay, binary multiplexing, bounded transport pooling, private SG subscription delivery, atomic lifecycle management, and backup/update coverage.

**Architecture:** SG-Gateway remains the Python control plane. A separate Go runtime implements the SG-Net data plane. SG-Net is stored as a standalone `connection_settings` engine and uses existing `devices`/`device_credentials` rows for per-device identity. Public TCP/443 remains owned by the existing 23.01 Single Edge. SG-Net itself listens on loopback TCP/10448 and is reached through the existing nginx `ssl_preread` hub by a configurable SG-Net TLS server name; no custom cleartext marker or public SG-Net handshake is introduced.

**Tech Stack:** Python 3.12, Flask, SQLite, pytest, Go 1.24.x, Go standard library (`crypto/tls`, `crypto/hmac`, `crypto/sha256`, `net`, `encoding/binary`), systemd, nginx stream `ssl_preread`.

**Spec:** `docs/superpowers/specs/2026-09-17-sg-net-v1-design.md`

**Interfaces:**

```go
type FrameType uint8

const (
    FrameAuth FrameType = 0x01
    FrameAuthOK FrameType = 0x02
    FrameOpen FrameType = 0x10
    FrameData FrameType = 0x11
    FrameDatagram FrameType = 0x12
    FrameClose FrameType = 0x13
    FramePing FrameType = 0x20
    FramePong FrameType = 0x21
    FrameGoAway FrameType = 0x22
    FrameError FrameType = 0x23
)

type Header struct {
    Version uint8
    Type FrameType
    Flags uint16
    StreamID uint32
    Length uint32
}

func EncodeHeader(h Header) ([12]byte, error)
func DecodeHeader(raw []byte) (Header, error)
```

Set `ProtocolMajor = 1`, `MaxFramePayload = 1 << 20`, reject unknown version, zero/oversized malformed lengths, and frame types outside the defined set where context requires strict parsing.

Authentication API:

```go
type ClientProofInput struct {
    DeviceID uint64
    ClientNonce [32]byte
    ServerNonce [32]byte
    ProtocolMajor uint8
}

func ComputeProof(secret []byte, in ClientProofInput) [32]byte
func VerifyProof(secret []byte, in ClientProofInput, proof []byte) bool
```

Use HMAC-SHA256 and `hmac.Equal`.
