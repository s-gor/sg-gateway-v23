# Single Edge 443 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make TCP/443 the single public SG-Gateway TCP entrypoint while moving migrated Xray/NaiveProxy backends to loopback listeners and preserving independent UDP behavior.

**Architecture:** Nginx `stream` owns public TCP/443 and routes by TLS ClientHello/SNI using `ssl_preread`; Reality is passthrough and remains the unknown-SNI fallback. Xray and NaiveProxy TCP backends bind to `127.0.0.1` only. Client exports advertise public port 443; internal listener ports remain private implementation details.

**Tech Stack:** Bash installer/update scripts, Nginx stream, Python/pytest, Xray 26.9.9+, systemd.

**Spec:** `docs/superpowers/specs/2026-09-15-single-edge-443-design.md`

## Global Constraints

- Modify only `s-gor/sg-gateway-v23`, branch `feat/2301-single-edge-443` until acceptance.
- Do not modify `sg-gateway-v22`.
- SG-InfoSec is out of scope.
- TCP/443 is the only public SG-Gateway TCP listener after migration.
- UDP remains independent; Hysteria2 behavior is unchanged in this phase.
- AWG3.1 may use UDP/443 independently of TCP/443.
- Reality must remain TLS passthrough and the unknown-SNI fallback.
- Migrated backend listeners must bind to `127.0.0.1`.
- New exported links for migrated TCP protocols must advertise public port 443.
- Every production change is test-first.
