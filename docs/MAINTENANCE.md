# Maintenance и диагностика

## Clients, Keys & HTTPS

Для переноса между архитектурными линиями используйте именно профиль **Clients, Keys & HTTPS**, а не обычную SQLite-копию и не перенос старого runtime вручную.

В **Maintenance → Backups** нажмите **«Создать Clients, Keys & HTTPS»** и скачайте полученный `SG-Gateway-CLIENTS-*.sgbackup` на локальный компьютер.

В него входят клиенты, устройства, credentials, ключи, UUID, пароли, subscription-данные и активная HTTPS-идентичность: домен, сертификат и private key.

Не входят Routing, WARP, настройки протоколов, server runtime и старые listener/ports. После восстановления эти части конфигурируются заново под текущую архитектуру.

Для Restore выберите `.sgbackup`, сначала нажмите **«Проверить backup»**, затем **«Восстановить»**. До изменения данных SG-Gateway создаёт страховочную копию.

## Переход 22.08 → 23.01

Прямой in-place Update временно не поддерживается. Сохраните **Clients, Keys & HTTPS**, удалите 22.08, выполните Clean Install 23.01 и восстановите переносимый backup. Затем вручную включите нужные Connections и проверьте клиентские подключения.

## Другие резервные копии

Обычные SQLite-копии предназначены для локального восстановления базы. Полный server backup содержит также server-side runtime/configuration и подходит для переезда внутри совместимой архитектурной линии, но не используется как способ перенести старую runtime-схему 22.08 в Single Edge 23.01.

## Диагностика

Диагностика собирает состояние systemd-служб, backend, Xray, AmneziaWG, Mihomo, sing-box, конфигурационные проверки и ошибки последних операций. Секреты должны быть удалены из diagnostic bundle.

## Обновление 23.01

Update используется только внутри линии 23.01. Updater создаёт Safety Backup и выполняет rollback, если новая версия не проходит проверку.

## Проверка после изменений

- `System` открывается без Internal Server Error;
- `/health` отвечает;
- Nginx проходит `nginx -t`;
- Xray проходит `xray run -test`;
- нужные listeners активны;
- клиентская subscription строится;
- реальные клиентские подключения работают.
